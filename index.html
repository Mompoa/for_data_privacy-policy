Privacy Policy

Huling na-update: September 2026

Ang Privacy Policy na ito ay para sa Messenger bot ng Text2bot, na ginagamit para tumanggap ng mga order mula sa mga customer.

1. Anong impormasyon ang kinokolekta namin

Kapag ikaw ay nag-order gamit ang aming Messenger bot, kinokolekta namin ang mga sumusunod:

  • Pangalan ng customer
  • Pangalan ng produkto at quantity na inorder
  • Address para sa paghahatid ng order
  • Contact/phone number
  • Facebook Messenger ID (awtomatikong ibinibigay ng Facebook Messenger Platform para maipadala ang mga sagot)

2. Bakit namin kinokolekta ang impormasyong ito

Ginagamit lamang namin ang impormasyong ito para iproseso, kumpirmahin, at ihatid ang order mo. Wala kaming ibang layunin sa pagkuha ng data na ito.

3. Paano namin ini-imbak ang data

Ang mga order ay naka-store sa isang secure na database na aming pinapamahalaan. Tanging kami lamang, bilang may-ari ng negosyo, ang may access dito.

4. Pagbabahagi ng data

Hindi namin ibinebenta o ibinabahagi ang iyong personal na impormasyon sa ibang third-party companies. Ginagamit lamang ito internally para sa pagproseso ng order mo.

5. Katagalan ng pag-imbak

Itinatago namin ang impormasyon ng order hangga't kinakailangan para matapos ang transaksyon at para sa record-keeping ng negosyo.

6. Ang iyong mga karapatan

Maaari kang humingi na tanggalin o i-update ang iyong impormasyon anumang oras sa pamamagitan ng pakikipag-ugnayan sa amin gamit ang detalye sa ibaba.
